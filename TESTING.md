## Quick Start

1. Copy `.env.example` to `.env` and fill in values
2. Start the service:

```bash
   docker compose -f docker-compose.yml up -d
```

3. Install Playwright dependencies:
```bash
   npm ci
   npx playwright install --with-deps
```
4. Run smoke tests:
```bash
   npx playwright test
```
